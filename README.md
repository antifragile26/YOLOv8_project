# 圆柱全景图拼接程序

这是一个用于将多张照片拼接成圆柱形全景图的Python程序。

## 功能说明

### 主要功能
这个程序能够将相机水平旋转拍摄的一系列照片拼接成一张宽幅全景图。主要特点：

1. **自动参数提取**：从照片EXIF信息中自动读取相机焦距
2. **圆柱投影**：将平面图像投影到圆柱面上，消除透视畸变
3. **智能对齐**：使用SIFT特征匹配和RANSAC算法进行精确对齐
4. **水平位移拼接**：仅使用水平位移（不含旋转），更稳定可靠
5. **漂移校正**：通过首尾图像匹配修正累积误差
6. **平滑融合**：使用羽化技术消除拼接缝隙
7. **自动裁剪**：去除边缘无效区域

### 工作流程

```
加载图像 → 圆柱投影 → 特征提取 → 相邻帧匹配 → 漂移校正 → 图像融合 → 裁剪黑边 → 保存全景图
```

## 使用方法

### 安装依赖
```bash
pip install -r requirements.txt
```

### 基本用法
```bash
python cylindrical_panorama_stitching.py --input /path/to/images --output panorama.jpg
```

### 命令行参数
- `--input, -i`: 输入图像文件夹路径 **(必需)**
- `--output, -o`: 输出全景图文件名 (默认: `panorama.jpg`)
- `--focal, -f`: 手动指定焦距(像素)，EXIF读取失败时使用
- `--sensor-width, -s`: 传感器宽度(mm)，默认: 6.17 (1/2.3" 传感器)

### 示例

**基本拼接**：
```bash
python cylindrical_panorama_stitching.py -i ./photos -o my_panorama.jpg
```

**指定传感器参数** (全画幅相机)：
```bash
python cylindrical_panorama_stitching.py -i ./photos -o result.jpg --sensor-width 36.0
```

**手动指定焦距**：
```bash
python cylindrical_panorama_stitching.py -i ./photos --focal 1500
```

## 输出文件

运行后会生成：
- `panorama.jpg` (或指定的输出文件名) - 最终全景图
- `trans.txt` - 相邻帧的平移信息
- `trans_corrected.txt` - 漂移校正后的平移信息 (如果进行了校正)

## 技术细节

### 算法原理

1. **圆柱投影变换**
   - 将3D点 (x, y, z) 映射到圆柱面
   - 使用 `θ = arctan(x/z)` 和 `h = y/√(x²+1)`
   - 消除水平方向的透视畸变

2. **SIFT特征匹配**
   - 提取尺度不变特征点
   - 使用最近邻距离比率测试过滤匹配

3. **RANSAC水平位移估计**
   - 仅估算水平方向的平移 (dx)
   - 垂直方向位移固定为0
   - 更适合圆柱全景拼接场景

4. **漂移校正**
   - 匹配首尾图像计算闭环误差
   - 均匀分配误差到每一帧
   - 可选的焦距微调

5. **图像融合**
   - 羽化边缘 (feathering) 实现平滑过渡
   - 加权平均避免明显拼接缝

### 限制与注意事项

1. **适用场景**：相机绕垂直轴水平旋转拍摄
2. **不适用场景**：
   - 手持随意拍摄（会有旋转和垂直位移）
   - 场景深度变化剧烈（近景+远景）
   - 运动物体较多
3. **图片要求**：
   - 相邻图片需要30-50%重叠
   - 曝光尽量一致
   - 保留EXIF信息

## 常见问题

**Q: 拼接结果有明显接缝怎么办？**
A: 检查图片重叠度是否足够(建议30-50%)，尝试调整曝光设置使各张照片亮度一致。

**Q: 程序提示"匹配点不足"？**
A: 可能是图片重叠度太低，或场景特征点太少（如大片天空、白墙）。

**Q: 焦距读取失败？**
A: 使用 `--focal` 参数手动指定，或确保图片保留了EXIF信息。

**Q: 拼接结果扭曲变形？**
A: 可能焦距参数不准确，尝试用 `--sensor-width` 指定正确的传感器宽度。
